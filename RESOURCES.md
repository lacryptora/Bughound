# Resources

Curated public sources for the bug classes Bughound covers. Use these to confirm
findings, craft context-specific payloads, and actually learn each class. Every
bug-class skill under `skills/` has its own focused list too; this file holds the
cross-cutting references.

## All-purpose references
- **PayloadsAllTheThings** — payloads + methodology for every class: https://github.com/swisskyrepo/PayloadsAllTheThings
- **HackTricks** — the web-pentest wiki: https://book.hacktricks.wiki
- **PortSwigger Web Security Academy** — free labs + theory, the best way to learn a class hands-on: https://portswigger.net/web-security
- **OWASP Web Security Testing Guide (WSTG)**: https://owasp.org/www-project-web-security-testing-guide/
- **OWASP Cheat Sheet Series**: https://cheatsheetseries.owasp.org/

## Methodology
- **Jason Haddix — The Bug Hunter's Methodology (TBHM)**: https://github.com/jhaddix/tbhm
- **Intigriti — Crafting your bug bounty methodology (beginner guide)**: https://www.intigriti.com/researchers/blog/hacking-tools/crafting-your-bug-bounty-methodology-a-complete-guide-for-beginners
- **Bugcrowd — Bug Bounty Hunting Methodology**: https://www.bugcrowd.com/resources/levelup/bug-bounty-hunting-methodology-v2

## Writeups & newsletters (learn from real, disclosed bugs)
- **HackerOne Hacktivity** — disclosed reports, searchable by bug class: https://hackerone.com/hacktivity
- **Pentester Land** — curated bug bounty writeup list: https://pentester.land/writeups/
- **Intigriti Bug Bytes** — weekly community newsletter: https://www.intigriti.com/researchers/blog/bug-bytes
- **InfoSec Writeups** (Medium): https://infosecwriteups.com/

## Tooling collections
- **awesome-bugbounty-tools**: https://github.com/vavkamil/awesome-bugbounty-tools
- **ProjectDiscovery** — subfinder, httpx, katana, nuclei (the recon stack Bughound uses): https://github.com/projectdiscovery

---

> All of these are for authorized testing only. Confirm a program's scope before
> you run anything, and reproduce every finding by hand before you report it.
